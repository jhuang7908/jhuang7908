# CMC Atlas

The private therapeutic tables store computed sequence proxies for the same antibodies counted on the [evidence page](clinical-antibody-evidence.md):

- Engineered table, 458 antibodies with VH and VL: pI, GRAVY, instability index, net charge, and patch-style scores are columns in that table.
- Fully human table, 384 antibodies with VH and VL: the same class of columns.

These are calculated proxies. They are not measured solubility, aggregation, or manufacturing results.

## Public example

[muMAb4D5 CMC example](https://insynbio.com/case_mumab4d5_cmc.html) was reachable on 2 October 2026. It is one example assessment, not a benchmark across the 458 or 384 rows.

The console Atlas address returns a sign-in page, so it is not used as a public link. The website figure of 1,142 sequences is not the row count of these tables.
