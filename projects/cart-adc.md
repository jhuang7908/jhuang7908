# CAR-T and ADC materials

What is public today is a component browser and design examples. There is no claim here of a tool that compares options and returns a go or no-go development plan.

## Public pages

Checked on 2 October 2026:

- [CAR component browser](https://insynbio.com/component-browser.html). The page source records 237 elements, with metadata date 7 April 2026. Categories include binders, costimulatory domains, hinges, signaling domains, and safety switches.
- [ADC database](https://insynbio.com/adc_database.html). Public descriptive pages for ADC examples. A local ADC index of 10 rows does not include full sequences, so that file is not quoted as the size of the public ADC set.
- [Malaria CAR-M design example](https://insynbio.com/case_malaria_carm_design.html). A design case with literature citations. It is an example, not a completed preclinical package.
