# AbEngineCore

Private development covers antibody humanization comparisons: germline and framework context, parent-to-humanized sequence pairs, and written example reports.

A multi-factor framework ranking model is in development. It is not a frozen selector, and this page does not claim that it recovers clinical frameworks at a stated rate.

## Public example

[muMAb4D5 humanization example](https://insynbio.com/case_mumab4d5_humanization_en.html) was reachable on 2 October 2026. It walks through a published historical humanization case. It is an example report, not a locked validation of the current private code.

## Reference pairs used for audit

The clinical reference set is the 52 parent-to-humanized pairs in [Clinical antibody evidence](clinical-antibody-evidence.md). Literature sets (Hu-mAb 25, Humatch 25, HuAbDiffusion 22) are kept separate from that clinical set.

Pair counts are not a performance result for AbEngineCore.
